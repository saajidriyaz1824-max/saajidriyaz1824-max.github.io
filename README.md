# Sajid Riyaz — CSE-AI Portfolio

## Files
- `index.html` — page content and sections
- `style.css` — responsive visual design
- `script.js` — mobile menu and current footer year
- `profile.jpg` — add your own photo using this exact filename

## Run locally
1. Keep all files in the same folder.
2. Add a square portrait named `profile.jpg` to the folder.
3. Open `index.html` in a browser.

## Personalize before publishing
- Change the name, bio, education details and project descriptions in `index.html`.
- Replace `your-email@example.com` with your actual email address.
- Replace the sample GitHub profile links with individual repository links when available.
- Add your own photo as `profile.jpg`.
- Only list skills and projects that you can confidently explain.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io` (replace with your exact GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `profile.jpg` to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait a few minutes and visit `https://YOUR-USERNAME.github.io`.

If your repository name is not `YOUR-USERNAME.github.io`, the site URL will usually include the repository name after your username.
